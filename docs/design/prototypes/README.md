# 生命周期原型 — 六个工作区的离线设计预览

日期：2026-11-11。直接打开[lifecycle-workspace.html](lifecycle-workspace.html)。这是随仓设计文件，不是已改造的Vue页面；施工语义见[前端施工合同](../frontend-implementation-contract.md)，全站范围见[重设计方案](../frontend-redesign.md)与[页面清单](../frontend-pages.json)。

## 预览方式

浏览器直接打开HTML即可；无构建、无外部依赖、无网络请求。需要本地HTTP时，在本仓运行：

```bash
python3 -m http.server 8088 --bind 127.0.0.1 --directory docs/design/prototypes
```

然后打开`http://127.0.0.1:8088/lifecycle-workspace.html`。这只提供静态文件，不启动后端、不使用真实账号。端口被占用时自行选择空闲私有端口，勿复用共享开发服务。

## 看什么、怎么操作

- **工作台**：有任务读取资格的处置与配置样本显示工单、我发起的任务、消息三域；普通成员隐藏任务卡，工单/消息两卡自动等分宽度。工单近期截止信息并入工单卡和主列表；空业务菜单只保留安全工作台、个人消息与身份入口。点Logo可稳定返回。数字来自合成集合，不是项目真实指标。
- **我发起的任务**：点击任务卡只打开本人提交的在途/失败合成执行记录，在演示状态记录`submitted_by=me`意图；不请求任务API。原型用角色样本表达能力差异，正式接线按服务端`task:read`与资源授权，不能凭角色名称推断权限。
- **工单列表**：展开更多筛选，修改截止条件再收起，已生效chips仍可见；选择本页两项，添加一个标签并查看逐项回执。工单ID使用超出JS安全整数范围的string样本。新建主操作在有创建能力的角色标题右侧。
- **工单详情**：从工单标题进入，核对主内容/责任侧栏、来源与本地证据、活动流。处置角色可演示分派和提交复测，只有本页状态变化。
- **情报查询**：左右主从；选择历史只回填值，再明确查询。记录仅表示本机成功查询元数据，不是结果快照；示例IP/域名为保留示例值，没有真实威胁评分。
- **业务助手**：切到处置与配置角色，修改配置后离开触发保护；生成计划，核对时间/时区/范围/执行上限，显式勾选才可确认。普通角色不能确认无权写入；确认不会创建真实计划或工单。已有企业助手与平台领域助手双轨均为现有API连接，不提供模型部署。
- **设备**：内部扩展示例，展示正常/陈旧/未知状态与来源时间；普通角色只读，有入口权限的角色可点“打开管理页”看本地说明。没有SSO，默认人工登录；自动登录需逐厂商、固件、方式验证，监控/访问代理/运维网关供给仍待确认。没有真实设备地址或凭据。

顶部设计预览控制可切三种角色、正常/加载/空/错误、常规/紧凑密度。内部应用还演示独立服务入口和简单表单，全部只开本地说明；这不代表稳定扩展接缝已实现。所有人名、部门、厂商、记录、状态和时间完全合成，未使用脱敏真实业务数据。

## 本轮检查结果

既有缓存Playwright Chromium对六视图分别检查1366×768、1440×900、1920×1080和390×844；文档/外层无水平溢出，表格允许局部横向滚动。检查了跳转主内容、键盘焦点、Esc返回、筛选条件保留、本页选择/批量标签、明确重查、配置离开保护、角色动作限制、计划明确确认、空业务菜单、六视图加载/空/错误、设备入口与无外部网络请求。本轮23组检查通过，留存36张截图。截图和机器结果在本轮本地ignored审计收据保存，不把大量PNG提交仓库。

720×450有效布局视口用于观察1440×900在200%缩放时的重排趋势；它不是原生浏览器缩放验收。CSS zoom不能等效媒体查询重排，未用作通过证据。原型为亮色样板，尚未验证暗色、屏幕阅读器、真实设备触屏、生产Vue/Element Plus、真实API/权限、网络乱序或批量部分失败。后续UI实施仍需六件门禁和对应真实栈证据，不能用本轮离线检查替代。
