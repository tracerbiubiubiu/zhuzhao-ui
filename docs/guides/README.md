# 开发指南 — 按步骤完成一个任务

- 初次启动与真实上游准备：[开发与联调](development.md)。
- 新增/改动页面：先读[设计约束](../design/frontend-ui.md)，再按[组件指南](components.md)选择骨架、分页与共用资产。
- 接列表/表单控制器：[hooks使用](hooks.md)，注意 string ID 与 data/list 契约。
- 新增测试或交付：[测试指南](testing.md)，分清本轮结果、测试能力与历史证据。

提交与协作步骤见[贡献指南](../contributing.md)，部署操作见[运维入口](../ops/README.md)。
